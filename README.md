# 🐍 Python Interview Preparation (SDE Prep)

Welcome to the **Python Interview Preparation** repository by **Karthik Bhandarkar**. This repository serves as a systematic, topic-by-topic portfolio for mastering Python fundamentals, data structures, algorithms, and technical interview problem solving.

---

## 📁 Repository Navigation

### 1. 📘 [Python-Basics](./Python-Basics/)
Comprehensive modular topic modules with solution scripts, docstrings, complexity analyses, and dedicated topic documentation:

- [**01. Print Statements**](./Python-Basics/01-Print-Statements/) - Output formatting, escape characters (`\n`, `\t`), quotes, and ASCII art patterns.
- [**02. Variables**](./Python-Basics/02-Variables/) - Variable declaration, dynamic typing, `a, b = b, a` tuple unpacking swap, and data types.
- [**03. Input & Type Conversion**](./Python-Basics/03-Input-TypeConversion/) - Dynamic user input with `input()`, numeric type casting (`int()`, `float()`), and formula evaluation.
- [**04. Strings**](./Python-Basics/04-Strings/) - String indexing, slicing `[start:stop:step]`, f-strings, and string methods.
- [**05. Operators**](./Python-Basics/05-Operators/) - Arithmetic, float division vs floor division (`/` vs `//`), modulus (`%`), operator precedence, and math helpers.
- [**06. If-Else**](./Python-Basics/06-If-Else/) - Conditional branching (`if`, `elif`, `else`), logical operators (`and`, `or`, `not`), nested conditionals, HackerRank & GFG problems.
- [**07. While Loop**](./Python-Basics/07-While-Loop/) - Counter patterns, accumulators, digit extraction (`% 10`, `// 10`), number reversal, and palindrome verification.
- [**08. For Loop**](./Python-Basics/08-For-Loop/) - Iteration with `range()`, step values, reverse loops, sum/product accumulators, and multiplication tables.
- [**09. String Algorithms**](./Python-Basics/09-String/) - Index & direct string traversal, reverse iteration, vowel counting, and linear search.

## 🚀 Quick Start

To clone and run any problem script locally:

```bash
# Clone repository
git clone https://github.com/Karthik-bhandarkar/sde-interview-prep.git

# Navigate to topic folder
cd sde-interview-prep/Python-Basics/01-Print-Statements

# Run any problem script
python 01_hello_world.py
```
